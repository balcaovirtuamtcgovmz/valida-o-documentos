# Projeto GitHub Pages — Consulta de Permit

Versão estática criada a partir do HTML fornecido para exercício de curso.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `css/`, `js/` e `images/`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Guarde e aguarde a publicação.

Esta versão não usa PHP, Livewire, sessões ou tokens do servidor original.
